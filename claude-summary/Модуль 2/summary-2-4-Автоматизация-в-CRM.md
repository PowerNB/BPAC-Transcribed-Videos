# Автоматизация бизнес-процессов в Bitrix24 (Модуль 2, Урок 4)

## О чём этот урок

Урок посвящён автоматизации бизнес-процессов в разделе CRM системы Bitrix24, а также обзору дополнительных объектов (интернет-магазин), поддерживающих бизнес-процессы. Рассматривается, как роботы, триггеры и шаблоны бизнес-процессов работают совместно для автоматизации обработки лидов, сделок и заказов. Урок является вводным перед практическим созданием бизнес-процессов и помогает понять общую архитектуру автоматизации в Bitrix24.

---

## Основные понятия

| Термин | Определение |
|---|---|
| **Бизнес-процесс (БП)** | Автоматизированная последовательность действий, запускаемая на создание, изменение объекта или вручную |
| **Робот** | Упрощённая «обёртка» над бизнес-процессом; упрощённый интерфейс для создания автоматизации, доступный бизнес-пользователям |
| **Триггер** | Условие или событие, запускающее автоматизацию (робота или бизнес-процесс) |
| **Шаблон бизнес-процесса** | Готовая схема БП, доступная для запуска из контекстного меню объекта (лида, сделки и т.д.) |
| **Дизайнер бизнес-процессов** | Визуальный редактор для создания и редактирования сложных БП; единый для всех объектов Bitrix24 |
| **Лид** | Объект CRM, представляющий потенциального клиента или заявку |
| **Сделка** | Объект CRM, представляющий процесс продажи |
| **Стадия** | Этап воронки, по которому последовательно движется лид или сделка |
| **Заказ** | Основной объект интернет-магазина в Bitrix24, поддерживающий автоматизацию через роботов и БП |

## Бизнес-процессы в CRM

### Где находятся настройки БП для CRM

- Раздел **CRM → Настройки → Бизнес-процессы**
- Также есть подраздел **«Роботы бизнес-процесса»**
- В настройках перечислены все **сущности CRM**, по которым можно создавать БП:
  - Лиды
  - Сделки
  - Контакты
  - Компании
  - и другие объекты CRM

### Как запускаются БП в CRM

БП в CRM могут запускаться тремя способами:

1. **На создание объекта** — автоматически при добавлении нового лида/сделки
2. **На изменение объекта** — автоматически при изменении данных существующего лида/сделки
3. **Вручную** — через контекстное меню объекта в списке

### Шаблоны БП в списке лидов

- В списке лидов в **контекстном меню** строки доступна опция «Запустить бизнес-процесс»
- Отображаются только те шаблоны, которые созданы для данной сущности
- Шаблоны хранятся в **CRM → Настройки → Бизнес-процессы → Лиды → Список шаблонов**

## Роботы в CRM: принцип работы и связь с дизайнером БП

### Что такое робот

- Робот — это **упрощённый интерфейс** для создания автоматизации, ориентированный на бизнес-пользователей (не разработчиков)
- По сути, робот — это **«обёртка»** над стандартным бизнес-процессом
- Внутри робот устроен так же, как полноценный бизнес-процесс

### Возможность редактирования роботов в дизайнере

1. Открыть настройку роботов для нужной сущности (например, лиды)
2. Нажать кнопку **«Настройка»**
3. Система предложит **открыть дизайнер бизнес-процессов**
4. В дизайнере доступно полноценное редактирование с блоками, условиями и действиями

> **Важно:** Интерфейс дизайнера бизнес-процессов **единый** для всех объектов — лидов, документов на диске, процессов в живой ленте. Блоки и логика одинаковы.

## Специфика автоматизации объектов CRM (vs. документы и живая лента)

### Почему CRM сложнее

Автоматизация в CRM **более сложная**, чем для документов или живой ленты, по следующим причинам:

| Фактор сложности | Пояснение |
|---|---|
| **Стадии воронки** | Лиды и сделки движутся по стадиям; автоматизация привязана к переходам между ними |
| **Роботы** | Работают параллельно с полноценными БП; нужно понимать, что запускается когда |
| **Триггеры** | Запускают роботов при наступлении условий; также работают параллельно |
| **Полноценные БП** | Запускаются на создание, изменение или вручную; работают совместно с роботами |

### Три инструмента автоматизации CRM, работающих совместно

```
Стадии воронки
    ├── Роботы (привязаны к стадиям, упрощённый интерфейс)
    ├── Триггеры (условия запуска роботов)
    └── Бизнес-процессы (запуск на создание / изменение / вручную)
```

### Рекомендация из урока

> Перед созданием БП для CRM — **сначала освоить базовый инструментарий** на простых объектах (процессы в живой ленте), чтобы понять принципы работы дизайнера, а затем переходить к более сложным CRM-сценариям.

## Интернет-магазин в Bitrix24 и поддержка бизнес-процессов

### Основной объект — Заказ

- В Bitrix24 встроен **интернет-магазин** как отдельный модуль
- Основная сущность — **Заказ**, который движется по стадиям (аналогично лиду/сделке)
- Для заказов доступны:
  - **Роботы** (настройка автоматизации)
  - **Дизайнер бизнес-процессов** (редактирование через полноценный дизайнер)

### Вывод

Интернет-магазин — ещё один объект Bitrix24, который **полноценно поддерживает бизнес-процессы**. Логика та же: роботы, триггеры, стадии + возможность редактирования через дизайнер БП.

## Единство дизайнера бизнес-процессов

Ключевая архитектурная особенность Bitrix24: **один дизайнер — для всех объектов**.

| Объект | Поддержка дизайнера БП |
|---|---|
| Документы на Диске | ✅ |
| Процессы в живой ленте | ✅ |
| Лиды CRM | ✅ |
| Сделки CRM | ✅ |
| Заказы интернет-магазина | ✅ |
| Роботы (все объекты) | ✅ (через кнопку «Настройка») |

> Один раз освоив дизайнер на простом примере — вы можете применять знания ко всем объектам.

## Пошаговые инструкции

### Как запустить бизнес-процесс на лид вручную

1. Перейти в раздел **CRM → Лиды**
2. Найти нужный лид в списке
3. Открыть **контекстное меню** строки (кнопка «…» или правая кнопка мыши)
4. Выбрать пункт **«Запустить бизнес-процесс»**
5. Выбрать нужный шаблон из предложенного списка
6. Подтвердить запуск

### Как просмотреть шаблоны БП для лидов

1. Перейти в **CRM → Настройки**
2. Найти раздел **«Бизнес-процессы»**
3. Выбрать сущность **«Лиды»**
4. Перейти в **«Список шаблонов»**
5. Здесь отображаются все шаблоны, доступные для ручного запуска

### Как открыть роботов в дизайнере бизнес-процессов

1. Перейти в настройку **роботов** для нужного объекта CRM (или интернет-магазина)
2. Нажать кнопку **«Настройка»** (или аналогичную)
3. В появившемся предложении выбрать **«Редактировать в дизайнере бизнес-процессов»**
4. Дизайнер откроется с текущей схемой робота — её можно расширять и усложнять

## Главное

1. **CRM поддерживает три вида запуска БП:** на создание объекта, на изменение объекта и вручную через контекстное меню.
2. **Робот — это упрощённый бизнес-процесс.** Внутри это тот же механизм, и его можно редактировать в полноценном дизайнере.
3. **Дизайнер бизнес-процессов единый** для всех объектов Bitrix24 (диск, живая лента, CRM, магазин) — освоив его один раз, применяешь везде.
4. **Автоматизация в CRM сложнее**, чем для документов, потому что включает три параллельных инструмента: роботов, триггеры и полноценные БП.
5. **Стадии воронки** — ключевой элемент CRM, к которому привязаны роботы и триггеры.
6. **Интернет-магазин** (заказы) — полноценный объект с поддержкой роботов и дизайнера БП.
7. **Стратегия обучения:** сначала изучить дизайнер на простых объектах (живая лента/диск), затем переходить к сложной CRM-автоматизации.
8. **Шаблоны БП в контекстном меню** — удобный способ ручного запуска процессов прямо из списка лидов/сделок.
9. **Роботы и полноценные БП существуют параллельно** — они не заменяют, а дополняют друг друга.
10. **Перед изучением CRM-процессов** необходимо понять базовую структуру дизайнера: блоки, действия, условия — это общая основа для всей автоматизации в Bitrix24.
