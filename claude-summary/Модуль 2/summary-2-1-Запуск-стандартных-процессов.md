# Бизнес-процессы в Битрикс24 — Запуск стандартных процессов

## О чём этот урок

Урок знакомит с тем, как бизнес-процессы реализованы в Bitrix24: где они доступны, как их активировать и как установить стандартные шаблоны. Это базовый урок модуля 2, закладывающий понимание архитектуры бизнес-процессов в системе перед переходом к их настройке и автоматизации.

---

## Основные понятия

| Термин | Определение |
|---|---|
| **Бизнес-процесс (БП)** | Автоматизированная последовательность действий, запускаемая для объекта в Bitrix24 (документа, сделки, контакта и др.) |
| **Стандартные шаблоны БП** | Готовые типовые процессы, поставляемые вместе с Bitrix24 (например, согласование документа, ознакомление) |
| **Демо-режим** | Временный (30 дней, однократно) доступ ко всему функционалу облачного Bitrix24, включая бизнес-процессы |
| **Общий диск** | Раздел Bitrix24 для хранения документов компании; один из объектов, поддерживающих запуск БП |
| **Настройка бизнес-процессов** | Пункт в настройках раздела, активирующий возможность работы с БП для конкретного объекта |

---

## Где доступны бизнес-процессы в Bitrix24

Бизнес-процессы можно запускать для следующих объектов:

- **Диск** — для документов (файлов на общем диске)
- **Живая лента** — процессы, связанные с обсуждениями и новостями
- **Группы / Списки** — для элементов списков внутри рабочих групп
- **CRM** — для нескольких сущностей:
  - Лиды
  - Сделки
  - Контакты
  - Компании

> Важно: бизнес-процессы доступны **не на всех тарифах**. На бесплатном тарифе эта функциональность недоступна.

---

## Тарифы и доступность бизнес-процессов

- **Бесплатный тариф** — бизнес-процессы **недоступны**; в настройках раздела нет соответствующего пункта
- **Платные тарифы** — бизнес-процессы включены
- **Демо-режим** — даёт полный доступ ко всем возможностям облачного Bitrix24 (включая БП) на **30 дней**, однократно для портала

### Как использовать демо-режим для обучения

Рекомендуемая стратегия при самостоятельном обучении:
1. Зарегистрировать новый облачный портал Bitrix24
2. Активировать демо-режим (30 дней бесплатно, все функции)
3. За этот период изучить и протестировать бизнес-процессы в полном объёме

---

## Пошаговые инструкции

### 1. Активация бизнес-процессов для документов на Диске

> Применимо: свежезарегистрированный портал с демо-режимом или платным тарифом

1. Перейти в раздел **Диск → Общий диск**
2. Открыть **Настройки** раздела (значок шестерёнки или меню настроек)
3. Найти и активировать пункт **«Настройка бизнес-процессов»**
4. После активации в меню раздела появится пункт **«Бизнес-процессы»**
5. Перейти в **Бизнес-процессы** — здесь будет пустой список шаблонов
6. Нажать кнопку создания **стандартных шаблонов** — система установит типовые БП

### 2. Запуск бизнес-процесса для файла на Диске

> Применимо: БП активированы и шаблоны установлены

1. Перейти в **Диск → Общий диск**
2. Загрузить или выбрать существующий документ
3. Открыть **контекстное меню** файла (правая кнопка мыши или «...»)
4. Выбрать пункт **«Запустить бизнес-процесс»**
5. Выбрать нужный шаблон из списка доступных стандартных процессов
6. Заполнить параметры запуска (если требуется) и подтвердить

### 3. Включение демо-режима на новом портале

1. Зарегистрировать портал на **bitrix24.ru**
2. В интерфейсе найти предложение активировать **демо-режим / пробный период**
3. Подтвердить активацию — портал получит все возможности верхнего тарифа на 30 дней
4. После активации вернуться в **Диск → Общий диск → Настройки** — пункт «Настройка бизнес-процессов» станет доступен

## Интерфейс бизнес-процессов

- **Контекстное меню файла** — точка входа для запуска БП из документа
- **Раздел «Бизнес-процессы»** в настройках объекта — управление шаблонами (просмотр, создание, установка стандартных)
- **Лента новостей** — запущенные процессы могут отображаться в живой ленте; там же удобно обсуждать вопросы по текущему процессу
- **Процессы** (отдельный раздел) — централизованное место для работы с запущенными экземплярами БП

---

## Автоматизация в CRM

Bitrix24 предоставляет широкие возможности автоматизации в CRM:
- Бизнес-процессы для лидов, сделок, контактов и компаний
- Дополнительно: функциональность **интернет-магазина** (встроена в платформу)

---

## Главное

1. **БП поддерживаются несколькими объектами**: Диск, Живая лента, Списки в группах, CRM (лиды, сделки, контакты, компании)
2. **На бесплатном тарифе бизнес-процессы недоступны** — необходим платный тариф или демо-режим
3. **Демо-режим** — быстрый способ получить полный доступ к БП для обучения: 30 дней, бесплатно, один раз на портал
4. **Стандартные шаблоны БП** не устанавливаются автоматически — их нужно установить вручную через раздел «Бизнес-процессы» в настройках
5. **Активация БП на Диске** — двухшаговая: сначала включить в настройках раздела, затем установить шаблоны
6. **Запуск БП для файла** выполняется через контекстное меню документа на Общем диске
7. **Обсуждение запущенного процесса** удобно вести прямо в живой ленте — это часть стандартного интерфейса Bitrix24
8. **CRM — основная зона автоматизации**: максимальные возможности для БП сосредоточены именно там
