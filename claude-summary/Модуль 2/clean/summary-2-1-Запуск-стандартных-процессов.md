# Запуск стандартных процессов

## О чём этот урок

Базовый урок модуля 2 курса по автоматизации бизнес-процессов в Bitrix24. Знакомит с тем, где доступны бизнес-процессы, как их активировать и как установить стандартные шаблоны. Закладывает понимание архитектуры БП в системе перед переходом к настройке и автоматизации.

---

## Основные понятия

| Термин | Определение |
|---|---|
| Бизнес-процесс (БП) | Автоматизированный процесс, запускаемый для объектов в Bitrix24 (файлов, сделок, элементов списков и т.д.) |
| Шаблон бизнес-процесса | Заготовленная схема БП, по которой создаются экземпляры процессов |
| Типовые (стандартные) БП | Готовые шаблоны от Bitrix24 (например, «Простое утверждение», «Голосование»), устанавливаемые вручную |
| Демо-режим | Пробный период на 30 дней с полным доступом ко всем возможностям облачного Bitrix24, однократно на портал |
| Экземпляр БП | Конкретный запущенный процесс на основе шаблона |

---

## Где доступны бизнес-процессы

Бизнес-процессы можно запускать для следующих объектов:

- **Диск** — для документов (файлов на общем диске)
- **Живая лента** — процессы, связанные с обсуждениями и новостями
- **Группы / Списки** — для элементов списков внутри рабочих групп
- **CRM** — для нескольких сущностей:
  - Лиды
  - Сделки
  - Контакты
  - Компании

> **CRM — основная зона автоматизации:** максимальные возможности для БП сосредоточены именно там.

---

## Доступность по тарифам

| Тариф | Доступность БП |
|---|---|
| Бесплатный | ❌ Недоступны; в настройках раздела нет соответствующего пункта |
| Платные тарифы | ✅ Включены |
| Демо-режим | ✅ Полный доступ ко всем возможностям на 30 дней, однократно для портала |

---

## Интерфейс и точки входа

- **Контекстное меню файла** — точка входа для запуска БП из документа (правая кнопка мыши или «...»)
- **Раздел «Бизнес-процессы» в настройках объекта** — управление шаблонами: просмотр, создание, установка стандартных
- **Лента новостей (Живая лента)** — запущенные процессы могут отображаться здесь; удобно обсуждать вопросы по текущему процессу
- **Раздел «Процессы»** — централизованное место для работы с запущенными экземплярами БП

## Пошаговые инструкции

### 1. Включение демо-режима на новом портале

1. Зарегистрировать портал на **bitrix24.ru**
2. В интерфейсе найти предложение активировать демо-режим / пробный период
3. Подтвердить активацию — портал получит все возможности верхнего тарифа на **30 дней**
4. После активации вернуться в **Диск → Общий диск → Настройки** — пункт «Настройка бизнес-процессов» станет доступен

---

### 2. Активация бизнес-процессов для документов на Диске

1. Перейти в раздел **Диск → Общий диск**
2. Открыть **Настройки раздела** (значок шестерёнки или меню настроек)
3. Найти и активировать пункт **«Настройка бизнес-процессов»**
4. После активации в меню раздела появится пункт **«Бизнес-процессы»**
5. Перейти в **Бизнес-процессы** — здесь будет пустой список шаблонов
6. Нажать кнопку создания стандартных шаблонов — система установит типовые БП

> ⚠️ **Важно:** Стандартные шаблоны **не устанавливаются автоматически** — их нужно установить вручную. Активация БП на Диске — **двухшаговая**: сначала включить в настройках раздела, затем установить шаблоны.

---

### 3. Запуск бизнес-процесса для файла на Диске

1. Перейти в **Диск → Общий диск**
2. Загрузить или выбрать существующий документ
3. Открыть **контекстное меню файла** (правая кнопка мыши или «...»)
4. Выбрать пункт **«Запустить бизнес-процесс»**
5. Выбрать нужный шаблон из списка доступных стандартных процессов
6. Заполнить параметры запуска (если требуется) и подтвердить

---

### 4. Рекомендуемая стратегия при самостоятельном обучении

1. Зарегистрировать **новый облачный портал** Bitrix24
2. Активировать **демо-режим** (30 дней бесплатно, все функции)
3. За этот период изучить и протестировать бизнес-процессы в полном объёме

---

## Главное

1. **БП поддерживаются несколькими объектами:** Диск, Живая лента, Списки в группах, CRM (лиды, сделки, контакты, компании).
2. **На бесплатном тарифе бизнес-процессы недоступны** — необходим платный тариф или демо-режим.
3. **Демо-режим** — быстрый способ получить полный доступ к БП для обучения: 30 дней, бесплатно, **один раз на портал**.
4. **Стандартные шаблоны не устанавливаются автоматически** — их нужно установить вручную через раздел «Бизнес-процессы» в настройках.
5. **Активация БП на Диске — двухшаговая:** сначала включить в настройках раздела, затем установить шаблоны.
6. **Запуск БП для файла** выполняется через контекстное меню документа на Общем диске.
7. **Шаблоны можно устанавливать из файлов диска** — это стандартный способ развернуть типовые процессы в новом портале.
8. **Обсуждение запущенного процесса** удобно вести прямо в живой ленте — это часть стандартного интерфейса Bitrix24.
9. **CRM — основная зона автоматизации:** максимальные возможности для БП сосредоточены именно там.
10. **Централизованный контроль** над запущенными экземплярами БП ведётся через отдельный раздел «Процессы».
