# Модуль 3, Урок 6: Инструменты разработчика — Бизнес-процессы в Bitrix24

## О чём этот урок

Урок рассматривает работу с бизнес-процессами в Bitrix24 с точки зрения технического специалиста (разработчика). Разбираются базовые элементы дизайнера БП, которые необходимо освоить перед созданием собственных процессов: создание копий шаблонов, принципиальное различие между шаблоном и запущенным БП, параметры действий, калькулятор значений и модификаторы.

## Основные понятия

| Термин | Определение |
|---|---|
| **Шаблон бизнес-процесса** | Схема (конфигурация), по которой система запускает бизнес-процесс. Редактируется в дизайнере. Изменения в шаблоне влияют только на **новые** запуски. |
| **Запущенный бизнес-процесс** | Конкретный экземпляр БП, стартовавший по шаблону. В момент запуска копирует путь и ветвления из шаблона — последующие изменения шаблона на него не влияют. |
| **Дизайнер бизнес-процессов** | Визуальный редактор в Bitrix24 для построения шаблонов из действий. |
| **Действие** | Элементарный блок шаблона БП (задание, уведомление, условие и т.д.). |
| **Экспорт/импорт БП** | Механизм переноса шаблона между слотами в виде файла. Используется, в том числе, для создания копий. |
| **Параметры действия** | Настройки конкретного блока в шаблоне: что делать, кому, с какими данными. |
| **Вставка значений** | Подстановка динамических данных (полей документа, переменных) в параметры действий. |
| **Калькулятор** | Инструмент вычисления значений внутри БП — от простых арифметических операций до сложных формул. |
| **Модификаторы** | Преобразования типов и форматов данных при вставке значений (например, дата → строка, число → валюта). |

## Копия шаблона бизнес-процесса

### Зачем нужна копия

Перед экспериментами с существующим типовым БП (системным или рабочим) рекомендуется создать его копию. Это позволяет:
- безопасно изучать и изменять шаблон, не ломая оригинал;
- откатиться к исходному состоянию в любой момент;
- держать «боевой» шаблон нетронутым.

### Как создать копию: пошаговая инструкция

1. Перейти в нужный раздел Bitrix24 (например, **«Заявление на отпуск»**).
2. Открыть **«Настройка бизнес-процессов»**.
3. Создать **новый пустой шаблон**, дать ему понятное имя (например, `Копия — Заявление на отпуск`). Сохранить.
4. Открыть **оригинальный шаблон** (тот, который нужно скопировать).
5. Нажать **«Экспорт»** — система скачает файл шаблона (`.bpt` или аналог).
6. Вернуться в список шаблонов и открыть только что созданную **копию**.
7. Нажать **«Импорт»**, выбрать скачанный файл.
8. Подтвердить предупреждение: содержимое шаблона-копии будет заменено импортируемым — это именно то, что нужно.
9. После импорта убедиться, что шаблон отображается корректно. Сохранить.

> **Итог:** копия полностью идентична оригиналу. Дальнейшие эксперименты ведутся только в копии.

## Шаблон VS запущенный бизнес-процесс

### Ключевое различие (критически важно!)

```
Шаблон БП → (момент запуска) → Запущенный БП
```

- **Шаблон** — это «чертёж». Его можно редактировать в любой момент.
- **Запущенный БП** — это «живой экземпляр». В момент старта он **копирует** к себе весь путь: ветвления, действия, настройки.
- После запуска изменения в шаблоне **не влияют** на уже идущий процесс.
- Только **новые** запуски БП будут учитывать обновлённый шаблон.

### Практический пример из урока

> Сотрудник отправил заявление на отпуск. БП запустился и сейчас «лежит» у руководителя на согласовании. Разработчик в этот момент меняет шаблон. Руководитель получит задание по **старому** маршруту — изменения его не затронут. Следующий сотрудник, который подаст заявление, пойдёт уже по **новому** шаблону.

## Параметры действий и вставка значений

### Параметры действий

Каждое действие в шаблоне имеет собственные параметры — настройки, определяющие его поведение:
- **Кому** адресовано (конкретный пользователь, роль, поле документа).
- **Что** делать (текст задания, тема уведомления).
- **Когда** (срок, условие выполнения).
- **Какие данные** использовать (поля документа, переменные БП, константы).

### Вставка значений

В большинстве параметров можно вставлять **динамические значения** вместо статичного текста:
- Поля документа (например, `{=Document:NAME}` — имя документа).
- Переменные БП, заданные в самом шаблоне.
- Результаты предыдущих действий.
- Системные данные (текущая дата, пользователь и т.д.).

> Практический подход: сначала разбираемся с типовым БП, потом вносим первые изменения — это самый быстрый способ освоить вставку значений.

## Калькулятор

### Назначение

Инструмент для **вычисления значений** внутри бизнес-процесса. Используется там, где нужно получить результат на основе данных документа или переменных.

### Принцип освоения (из урока)

> «Сначала учимся вычислять 2+2» — начинать с простых арифметических выражений, постепенно переходя к сложным формулам.

### Возможности калькулятора

- Арифметика: `+`, `-`, `*`, `/`
- Работа со строками
- Работа с датами (разница дат, прибавление дней)
- Условные вычисления
- Встроенные функции (подробнее — helpdesk.bitrix24.ru/open/5428897)

> Ссылка на полную документацию по вычислению значений: **helpdesk.bitrix24.ru/open/5428897**

## Модификаторы

### Что такое модификатор

Преобразование, применяемое к значению **в момент его вставки**. Позволяет привести данные к нужному типу или формату без дополнительных действий в шаблоне.

### Примеры применения

- Дата → строка в нужном формате (например, `ДД.ММ.ГГГГ`).
- Число → строка с разделителями тысяч.
- Текст → верхний/нижний регистр.
- Преобразование типов для корректного сравнения в условиях.

## Главное

1. **Всегда работай с копией** — перед изменением любого типового или рабочего шаблона создай его копию через экспорт/импорт.
2. **Шаблон ≠ запущенный БП** — изменения в шаблоне не влияют на уже стартовавшие экземпляры процесса; только новые запуски пойдут по обновлённой схеме.
3. **Экспорт/импорт — универсальный инструмент переноса** — он же используется для резервных копий, миграции между порталами, передачи шаблонов.
4. **Изучи все категории действий** по официальной документации Поддержки24 — это фундамент для любой разработки БП.
5. **Вставка значений — ключевой навык** — большинство реальных БП требуют динамических данных; без умения вставлять значения шаблоны будут статичными и бесполезными.
6. **Калькулятор осваивай от простого к сложному** — начни с `2+2`, затем переходи к формулам с полями документа.
7. **Модификаторы решают проблемы типов** — если значение вставляется некорректно или в неверном формате, первым делом смотри на модификаторы.
8. **Документация Поддержки24 — основной справочник разработчика** — в ней описаны все действия, параметры, формулы и модификаторы.
9. **Первый шаг в разработке** — модифицировать существующий типовой БП, а не создавать с нуля; это быстрее даёт понимание структуры шаблона.
